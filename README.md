# АИС «Кафедральный кампус» — демонстрация Git Flow

Учебный репозиторий для практической работы:
- main      — стабильные релизы
- develop   — интеграционная ветка
- feature/* — разработка модуля «Электронный деканат»
- release/* — стабилизация релиза 2.0.0
- hotfix/*  — экстренное исправление 2.0.1

Релизы: v1.4.0 -> v2.0.0 -> v2.0.1
